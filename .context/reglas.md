# Reglas de MecanCloud

Las [reglas generales](<../../Vaults/jmartinez/Ecosistema/reglas.md>) definen el protocolo común.

## Restricciones específicas
No introducir React ni fallback SQLite: los .db antiguos son material legado. Mantener datos, firmas y releases existentes.

## Protocolo común
Aplicar las reglas generales enlazadas arriba: alcance, Git, respaldo, validación, secretos y autorización de operaciones de riesgo.
Las decisiones y restricciones particulares conservadas en este repositorio siguen siendo obligatorias.
